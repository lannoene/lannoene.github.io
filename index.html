Status: Emulator ready!

CIA files are currently unsupported, please use CXI files and CCI files instead.
Save data naming scheme: TitleName_TitleID_SaveDataFile. Example: Tomodachi Life_000400000008c300_savdataArc.txt
- If you need to add an underscore in the save filename, precede each inner-filename underscore with a \ (backslash)
Arguments:
-s: Use software rendering
-c: Disable fastinterp (use Dyncom)
-v: Print version in console
-t: Enable audio stretching
-u: Underclock CPU to 10%
-w: Use OpenGL rendering (default, buggy)
Unimplemented/unfinished arguments:
-f: Fullscreen mode
-i: Install & Run CIA
-n: Disable audio emulation

Log is disabled for now.
